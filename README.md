# Office Task Management System

## Overview

The **Office Task Management System** is a desktop-based application designed to help offices organize, assign, monitor, and manage daily tasks efficiently.

The application provides a graphical user interface that allows users to manage office activities, track task progress, and improve workplace productivity.

The system is developed primarily using **Java** and **JavaFX**, providing a user-friendly and interactive desktop experience.

## Features

- **Task Management:** Create, update, delete, and manage office tasks.
- **Task Assignment:** Assign tasks to employees or team members.
- **Task Tracking:** Monitor task progress and completion status.
- **Priority Management:** Categorize tasks based on their importance.
- **Employee Management:** Organize and manage employee information.
- **Graphical User Interface:** Interactive desktop interface developed with JavaFX.
- **Task Organization:** Keep office activities organized in one centralized system.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd Office-Task-Management-System
   ```

3. Open the project in your preferred Java IDE.

4. Configure the JavaFX SDK and required dependencies.

5. Build and run the application.
